- 주민번호·신분증·상세주소는 요구하지 않음

**02 앱 프로젝트 소개 / 심사 자료** (분량 제한 없음, 별지 추가 가능, **개인정보·실명 기재 금지**)

7. 참고자료(선택·가산점) — 화면 시안, 시연 영상, GitHub 저장소 등 파일 또는 링크
8. 숏폼 링크(선택·가산점 없음)

**03 개인정보 수집·이용 동의서** — 수집항목/보유기간/수탁사(스터닝) 고지

### 7.1 SDK 제공 상태 — ⚠ 기획을 좌우하는 제약
[근거: document.pleos.ai "프로젝트 생성 및 SDK 사용 신청", 2026-10-22 열람]

| SDK | 기능 | Playground 표시 (10.22) | 설명회 (10.28) |
|---|---|---|---|
| Vehicle SDK – **Vehicle State** | 차량 상태 조회 | **사용 가능 (신청 불필요)** | 개발 단계 권한 선언만으로 사용 `[49:36~49:52]` |
| **NaviHelper SDK** | 경로 안내 제어, 내비 정보 조회 | **사용 가능 (신청 불필요)** | 동일 `[49:36~49:52]` |
| Vehicle SDK – Vehicle Control | 차량 제어 | 준비 중 (Coming Soon, 신청 불가) | "제공 범위와 권한에 따라 일부 차량 기능 제어 가능" `[41:28~41:34]`, 미공개 SDK도 공모전에 제공 예정 `[37:08~37:19]`. **시점·범위 미정** |
| FusedLocation SDK | 위치 정보 | 준비 중 | 권한 선언만으로 사용 가능 `[49:45~49:52]` ⚠ 미검증 |
| TextToSpeech SDK | 음성 합성 | 준비 중 (서버 연결용 클라이언트 ID/Secret 필요) | 권한 선언만으로 사용 가능 `[49:45~49:52]` ⚠ 미검증 (ID/Secret 필요 여부 미언급) |
| SpeechToText SDK | 음성 인식 | 준비 중 | 권한 선언만으로 사용 가능 `[49:45~49:52]` ⚠ 미검증 |

- **권한 승인**: 개발·공모전 단계에서는 권한 신청·승인 불필요, `AndroidManifest`에 SDK 문서가 안내하는 `uses-permission`만 선언하면 에뮬레이터에서 호출 가능 `[43:41~44:08]`. 승인 확인은 **Pleos 앱마켓 배포 심사** 때 하며, 승인 안 된 권한을 선언하면 심사 불통과 `[44:11~44:31]`, `[49:52~50:03]`.
- ⚠ 설명회 발언과 Playground 표시가 다름 → STT·TTS·FusedLocation은 **에뮬레이터에서 실제 호출해 본 뒤** 핵심 기능에 넣을 것.

- 공모전 사이트는 "각 SDK의 제공 상태와 사용 조건은 공식 문서에서 확인"이라고만 적음 → 현재 확실히 쓸 수 있는 것은 **차량 상태 조회 + 내비게이션 연동**뿐.
- Vehicle SDK는 도메인별 `checkXXXCapabilities`로 지원 여부 확인 필수, 퍼미션은 사전 승인 범위 내에서만 사용 가능(미승인 시 앱 심사 불통과).
- 설명회(10.28)에서 SDK 제공 일정이 바뀔 수 있으므로 반드시 확인. 준비 중 SDK에 핵심 기능을 의존하는 기획은 2차 PT 실동작 시연에서 위험.
- 공모전 사이트의 음성 메모 예시(STT)는 현재 상태로는 에뮬레이터에서 실동작 불가능할 수 있음(추정).
- **에뮬레이터 실측 결과(2026-10-22)**: `vehicle-data-findings.md` 참고. 요점:
  - 차량 상태 268개 값 조회 성공.
  - **현재 차속 API 없음**.
  - 연료·트립·전비는 미지원(에뮬레이터 차량이 EV).
  - NaviHelper는 위치, 경로, TBT, 혼잡도, 도착 시 예상 SoC까지 동작.
  - 차량 값은 에뮬레이터 내부 웹 콘솔(포트 8088)로 바꿀 수 있고, 대부분 SDK 리스너로 즉시 들어옴 → 시연 영상 제작 가능.
  - 내비 모의 주행(위치 이동)은 없음 → 설명회 질문 ⑦로 추가할 것.
