# 시연 영상 시나리오 — 크롱 · 차슐랭 (v3.1, 2026-11-13)

앱 동작 순서는 확정 시연 시나리오([demo-scenario.md](demo-scenario.md))를 따른다. 이 문서는 **블렌더 상황 영상과 실제 구동 녹화를 어떤 순서로 잇는지**를 정한다.

두 앱이 한 문서를 같이 쓴다(크롱·차슐랭 저장소에 같은 내용). 블렌더 장면 파일과 렌더·녹화 결과는 용량 때문에 저장소 밖 작업 폴더 `demo-video/`에 둔다(이민하 PC).

## 1. 형식

| 항목 | 정한 것 |
|---|---|
| 편수 | 앱마다 1편. 크롱 약 1분 15초, 차슐랭 약 1분 30초 |
| 이어 붙이기 | 두 편 모두 같은 골드 아이오닉5. 크롱의 도착 장소 = 차슐랭의 충전소 |
| 화면 | 1920×1080, 30fps. 블렌더와 녹화 모두 16:9 전체 화면 |
| 소리 | 내레이션 없음. 앱 음성 안내(TTS) + 작은 배경음 |

전환 규칙

| 전환 | 방법 |
|---|---|
| 블렌더 → 녹화 | **항상** 블렌더 안에서 카메라가 인포테인먼트 화면으로 들어가 화면이 프레임을 채운 뒤 녹화로 넘어간다(약 2초). 블렌더 속 화면에는 이어질 녹화의 첫 장면을 붙여 둔다 |
| 녹화 → 블렌더 | 바로 컷 |
| 횟수 | 편당 블렌더 → 녹화 3번 |
| 겹침 | 없음. 블렌더 구간은 블렌더만, 녹화 구간은 에뮬레이터 화면만 |

자막 규칙

| 구간 | 규칙 |
|---|---|
| 블렌더 | **자막을 넣지 않는다.** 장면 안의 상황 표시 글씨만 쓴다('크루즈 해제', '500m', '충전 중', '충전 안 됨' 등) |
| 녹화 | 한 줄 자막(20자 안팎) + 아래쪽 작은 고지 문구(5절) |
| 처음·끝 | 시작 카드 2초(앱 이름 + 한 줄), 엔드카드 6초(로고 + 고지) |

## 2. 크롱 (약 1분 15초)

한 줄 요약: **여러 차가 크루즈를 끈 곳을 모아, 다음 차에게 500m 앞에서 알려 준다.**

| 시간 | 구분 | ID | 내용 | 녹화 자막 |
|---|---|---|---|---|
| 0:00~0:02 | 카드 | — | "크롱 — 크루즈 해제 다발 구간을 미리 알려 드립니다" | — |
| 0:02~0:20 | 블렌더 | `KB1` | 합류 구간에서 차들이 차례로 제동, 차마다 '크루즈 해제' 표시와 핀이 쌓이고 구간이 붉어짐 → 길가 주차장의 골드 아이오닉5(출발 전)로 이동 → **인포테인먼트 진입** | — |
| 0:20~0:28 | 녹화 | `KR1` | 첫 실행 동의 2개 + [시작하기] → 근처 해제 다발 구간 목록 4곳(가까운 순). 맨 위 판교JC 합류부 0.4 km · 해제율 40% · 500 차량·일 | "처음 한 번만 동의" → "여러 차의 해제 비율로 정한다" |
| 0:28~0:36 | 블렌더 | `KB2` | 크루즈 100km/h 주행(계기판 CRUISE 100), 앞쪽 붉은 구간까지 '500m' 표시 → **인포테인먼트 진입** | — |
| 0:36~0:44 | 녹화 | `KR2` | 내비 위로 앱이 올라오며 주황 배너 "500m 앞 크루즈 해제 잦은 구간" + 음성 → 내비로 자동 복귀 | "앱을 열지 않아도 500m 앞에서 알려 준다" |
| 0:44~0:50 | 블렌더 | `KB3a` | 합류 구간. 램프에서 올라온 차가 끼어듦 → 브레이크등 → 빨간 '크루즈 해제' 표시, 핀이 꽂힘. 계기판 90 | — |
| 0:50~0:56 | 블렌더 | `KB3b` | 정체 꼬리. 40km/h로 감속 → 회색 '크루즈 해제 · 40km/h 기록 안 함' 표시, 핀 없음. 계기판 40 | — |
| 0:56~1:01 | 블렌더 | `KB3c` | 충전소 주차 칸에 정차(계기판 P) → **인포테인먼트 진입** | — |
| 1:01~1:09 | 녹화 | `KR3` | 내비 위로 앱이 다시 올라오며 최근 주행 요약: 안내 1회 · 1곳 · 내가 보탠 기록 1건 → [해제 다발 구간 목록으로] | "두 번 해제했지만 기록은 1건" → "60km/h 미만 해제는 세지 않는다" |
| 1:09~1:15 | 카드 | — | 엔드카드 | — |

- `KR2`와 `KR3`은 주행 녹화 한 번(`drive.mp4`)의 앞·뒤 부분이다(내비를 앞에 두고 시작). 가운데(해제 2번)는 내비만 보이므로 잘라 낸다.
- 동의 직후 목록은 위치를 아직 못 받아 "거리 확인 중"으로 뜬다. 녹화 스크립트가 설정에 다녀와 가까운 순 + 거리로 바뀐 목록을 찍으므로, `KR1`은 그 사이(설정 화면)를 잘라 쓴다.
- 해제 순간 앱의 "크루즈 대기/작동" 글자 변화는 영상에 넣지 않는다. 기록 여부는 `KR3` 요약으로 보여 준다.

## 3. 차슐랭 (약 1분 30초)

한 줄 요약: **충전 결과를 차가 직접 기록하고, 실제로 충전한 사람만 평가한다. 실패도 차가 기록한다.**

충전 장면이 먼저, 충전소 고르기가 나중이다. 에뮬레이터 위치가 고정이라 충전은 항상 "시흥동 주민센터"로 잡히므로, 다른 곳으로 길안내한 뒤 충전하면 이름이 어긋난다.

| 시간 | 구분 | ID | 내용 | 녹화 자막 |
|---|---|---|---|---|
| 0:00~0:02 | 카드 | — | "차슐랭 — 차가 직접 기록하는 충전소 점수" | — |
| 0:02~0:12 | 블렌더 | `CB1` | 충전소 전경 → 주차 칸의 골드 아이오닉5 → **인포테인먼트 진입** | — |
| 0:12~0:17 | 녹화 | `CR1` | 첫 실행 동의 2개 + 차종 "아이오닉 5" + [시작하기] → 홈 | "처음 한 번만 동의" |
| 0:17~0:23 | 블렌더 | `CB2` | 충전구가 열리고 케이블 연결, 빛이 흐름, '충전 중' 표시 → **인포테인먼트 진입** | — |
| 0:23~0:44 | 녹화 | `CR2` | "충전 기록 중"이 저절로 뜸 → 40→80% → "인증 충전 완료" → 별 5개 + 태그 2개 + [평가 보내기] → 홈 "내 충전 기록 1건 · 인증" | "충전구를 열면 알아서 기록" → "실제로 충전한 기록만 '인증 충전'" → "평가는 3초" |
| 0:44~0:52 | 블렌더 | `CB3` | 저녁(다른 날). 케이블을 꽂았는데 빛이 없음, 충전기 화면 빨강, '충전 안 됨' 표시, 배터리 40%에 멈춤 → 케이블 분리 → **인포테인먼트 진입** | — |
| 0:52~1:21 | 녹화 | `CR3` | "충전 기록 중 40%"에서 시작 → "충전 실패를 기록했어요" → 홈 "내 충전 기록 2건 · 실패" → 내 기록: 실패 1건 · 인증 1건 → 점수순 목록 → 시흥동 주민센터 상세(최근 실패에 방금 시각) → 대왕판교IC 휴게소 상세(별점은 대부분 5점인데 점수 최하위) → 1위 판교 테크노밸리 E-pit 상세 → [길안내] → 내비 경로 | "아무것도 하지 않아도 차가 기록한다" → "다음 운전자에게 '최근 실패'로 보인다" → "점수 = 평균 별점 × (1 − 30일 실패율)" → "고른 곳으로 바로 길안내" |
| 1:21~1:25 | 블렌더 | `CB4` | 차가 충전소를 나가 도로로 | — |
| 1:25~1:31 | 카드 | — | 엔드카드 | — |

- SoC가 오르는 구간은 편집에서 빨리 감고 배속을 적는다. 실패 대기 35초는 녹화하지 않는다(`CR3`은 충전구를 닫기 직전부터 찍는다).
- `CR3`은 길어서 화면이 바뀔 때마다 자막을 바꿔 끊어 준다.

## 5. 녹화에 넣을 고지

| 어디에 | 문구 |
|---|---|
| `KR1` 목록, `KR2` | 위치는 에뮬레이터 고정 위치, 해제 다발 구간은 그 앞 400m에 둔 시드 데이터 |
| `KR3` | 크루즈 작동·해제는 에뮬레이터 값으로 대신함(실차 해제 값은 받을 수 없음) |
| `CR2` | SoC는 콘솔 주입, 충전 시간·kW는 시연 배속 ×120 |
| `CR3` 실패 | 시연 판정 기준: 인증 10초·실패 30초 (실제 기준 3분·2분) |
| `CR3` 목록 | 충전소와 다른 차량 기록은 시드 데이터(판교 반경 3km 10곳) |
| 엔드카드 | 위 내용 3줄 + "Pleos 에뮬레이터 실제 동작 녹화" |

## 6. 만드는 방법

| 무엇 | 어떻게 |
|---|---|
| 녹화 | 저장소에서 `bash tools/demo-video.sh crong`, `bash tools/demo-video.sh chachelin`. 화면 조작·차량 값 주입·녹화·주입 시각 기록을 한 번에 하고, 끝나면 동의를 철회해 서버에 올린 기록을 지운다 |
| 화면 그림 | 같은 스크립트가 각 녹화의 첫 장면을 `assets/*.png`로 캡처 |
| 블렌더 | `demo-video/cruisebreaker/build_cuts.py`, `demo-video/chachelin/build_cuts.py` (저장소 밖 작업 폴더) |
| 소리 | 화면 녹화(`adb screenrecord`)에는 소리가 없다. 음성 안내는 PC 소리를 따로 녹음해 `KR2`에 맞춘다 |
