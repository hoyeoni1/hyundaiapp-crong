안녕하세요. 현대자동차그룹 차량용 앱 개발 공모전에 일반 부문으로 참가하는 팀 "삼각고래"의 대표 장호연입니다.
저희 팀은 두 작품(차슐랭, 크루즈브레이커)을 준비하고 있으며, 공지와 FAQ, 온라인 설명회 내용을 확인했지만 찾지 못한 부분이 있어 문의드립니다.

### 1. 제출·심사 관련

1. **심사용 GitHub 계정**: 설명회에서 "공지된 심사용 계정을 콜라보레이터로 초대"하라고 안내해 주셨는데, 계정명이 아직 공지되지 않은 것 같습니다. 계정명과 초대 시점을 알려 주실 수 있을까요?
2. **저장소 주소 기입**: 접수양식 02 파트 7번에 GitHub 저장소 주소를 적어야 하는데, 저장소가 팀원 개인 계정 아래에 있습니다. 주소에 개인 계정명이 들어가는 것이 양식의 개인정보·계정정보 노출 금지 규정에 걸리는지 궁금합니다. 걸린다면 주소를 어떻게 적으면 될까요?
3. **시연 영상**: 길이 제한, 파일 형식, 제출 방식(메일 첨부 또는 링크)이 정해져 있는지 궁금합니다. 링크로 제출한다면 YouTube "일부 공개" 링크도 괜찮을까요?
4. **접수 메일 제목·작품 구분**: 사이트에는 제목이 `[차량용 앱 개발 공모전] 팀명_대표자명`으로 안내되어 있고, 설명회에서는 앱명을 넣으라고 하셨습니다. 한 팀이 두 작품을 낼 때 정확한 제목 형식은 무엇인지, 메일을 작품별로 따로 보내야 하는지 알려 주시면 감사하겠습니다.

### 2. 기술·앱마켓 심사 관련

5. **백그라운드 실행**: 다른 앱(내비 경로 안내 등)이 앞에 있을 때 Android 14가 앱을 동결해서 차량 신호를 받지 못했습니다. 에뮬레이터에서는 포그라운드 서비스(`foregroundServiceType="specialUse"`)와 부팅 완료 수신(`RECEIVE_BOOT_COMPLETED`)으로 해결했습니다. 이 두 가지를 Pleos 앱마켓 심사에서 허용하는지, 허용한다면 지켜야 할 조건(알림 표시, 사용자 동의 등)이 있는지 궁금합니다.
6. **주행 중 화면(DO)**: Activity에 `distractionOptimized`를 선언하면 에뮬레이터에서는 주행 중에도 화면이 표시됩니다. 앱마켓 배포본에서도 이 선언만으로 주행 중 화면이 허용되는지, 아니면 별도 심사나 등록 절차가 있는지 알려 주세요.
7. **실차 시동 off 동작**: 실차 헤드유닛은 시동을 끄면 완전히 종료되나요, 아니면 절전(suspend) 상태였다가 시동을 켜면 깨어나나요? 절전 방식이라면 시동을 켤 때 앱이 받을 수 있는 시스템 이벤트가 있는지도 궁금합니다.
8. **크루즈 해제 값**: Vehicle SDK `CruiseControlState`에서 실차는 운전자가 브레이크 등으로 크루즈를 해제할 때 어떤 값이 들어오는지 궁금합니다. Virtual Console에서는 활성(ACTIVATED)과 대기(ENABLED)만 재현됩니다.
9. **탑재 차종**: Pleos Connect를 처음 탑재하는 차종에 전기차가 포함되는지 알려 주실 수 있을까요? 전기차 충전 관련 작품의 사업성 추정에 필요합니다.
10. **Vehicle Control SDK**: 설명회에서 미공개 SDK도 공모전에 제공될 예정이라고 하셨는데, Vehicle Control SDK의 공개 시점과 범위가 정해졌는지 궁금합니다.
11. **TTS 권한**: 주행 중 안내 음성을 Pleos TTS SDK(`ai.pleos.playground:TextToSpeech`, 기기 내 모드)로 재생하려고 `pleos.car.permission.TTS_SERVICE` 권한을 선언했습니다. 이 권한이 앱마켓 심사에서 승인되는지, 별도 신청 절차가 있는지 알려 주세요.

바쁘신 와중에 확인해 주셔서 감사합니다.
