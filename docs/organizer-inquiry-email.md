### 1. 제출 관련 (접수 마감 전 확인이 필요합니다)

1. **심사용 GitHub 계정**: 비공개 저장소는 공지된 심사용 GitHub 계정을 Collaborator로 초대하라고 안내되어 있는데, 11월 9일 기준 공지사항·FAQ·참가 가이드에서 계정명을 찾지 못했습니다. 계정이 언제, 어디에 공지되는지 알려 주세요. 또 안내대로 개인 계정 비공개 저장소는 초대하면 쓰기 권한이 함께 주어지는데, 이대로 초대하면 되는지, 아니면 저장소를 공개(Public)로 바꿔 제출하는 편이 나은지도 궁금합니다.
2. **시연 영상**: 길이 제한이나 파일 형식이 있는지 알려 주세요. APK처럼 링크(예: YouTube 일부 공개)로 제출하면 되는지도 확인 부탁드립니다.

### 2. 출시 준비 관련 (공모전 심사와 무관하다면 나중에 답해 주셔도 됩니다)

3. **백그라운드 기록**: 두 앱은 시동을 걸면 자동으로 주행·충전을 기록합니다. 내비가 앞에 있을 때 Android 14가 앱을 동결해 차량 신호를 받지 못해, 포그라운드 서비스(`foregroundServiceType="specialUse"`)와 부팅 완료 수신(`RECEIVE_BOOT_COMPLETED`)을 사용했습니다. 앱마켓 심사에서 허용되는지, 지켜야 할 조건이 있는지 궁금합니다.
4. **주행 중 화면(DO)**: 크루즈브레이커는 주행 중 안내 화면을 보여 주기 위해 Activity에 `distractionOptimized`를 선언했고, 에뮬레이터에서는 주행 중에도 화면이 표시됩니다. 배포본에서도 이 선언만으로 허용되는지, 별도 심사나 등록이 필요한지 알려 주세요.
5. **시동 off 동작**: 실차 헤드유닛은 시동을 끄면 완전히 종료되나요, 절전(suspend) 후 깨어나나요? 절전 방식이라면 시동을 켤 때 앱이 받을 수 있는 시스템 이벤트가 있는지도 궁금합니다.
6. **크루즈 해제 값**: Vehicle SDK `CruiseControlState`에서 운전자가 브레이크 등으로 크루즈를 해제할 때 실차에서는 어떤 값이 들어오는지 궁금합니다. Virtual Console에서는 활성(ACTIVATED)과 대기(ENABLED)만 재현됩니다.
