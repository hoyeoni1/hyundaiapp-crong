## 3. 다음 세션이 할 일 (순서대로)

### 3.1 [사용자 결정] 42dot SDK 라이선스 동의
라이선스 전문은 아래 명령 실행 시 터미널에 표시되거나, Android Studio SDK Manager에서 설치 시 팝업으로 표시됨. 요지:
- 42dot이 SDK 소유. 무상 라이선스이나 사전 통지 후 과금 가능 조항(3.1.1) 있음.
- 개발자가 만든 앱의 권리는 개발자 소유(4.1).
- SDK 역공학·재배포·타 플랫폼 개발 사용 금지(3.2, 3.4).
- 보증 없음, 한국법·서울중앙지법 관할.

### 3.2 [방법 A] CLI로 시스템 이미지 설치 (권장, 재현 가능)
Git Bash 기준:
```bash
export JAVA_HOME="E:\\AndroidStudio\\jbr"
cd /e/Android/Sdk/cmdline-tools/latest/bin
./sdkmanager.bat --sdk_root=E:\\Android\\Sdk "system-images;android-34;pleos_car_emulator;x86_64"
```
- 실행하면 라이선스 전문이 출력되고 `Accept? (y/N)` 프롬프트가 뜸 → `y` 입력.
- 비대화형으로 돌리려면 `yes | ./sdkmanager.bat ...` (사용자가 동의한 후에만).
- 4.1 GB 다운로드이므로 백그라운드 실행 권장. 완료 후 `E:\Android\Sdk\system-images\android-34\pleos_car_emulator\x86_64\` 폴더가 생기면 성공.

### 3.2 [방법 B] Android Studio GUI로 설치 (공식 문서 절차)
1. Android Studio → Tools → SDK Manager → **SDK Update Sites** 탭 → "Pleos Connect System Image"가 이미 목록에 있는지 확인(없으면 `+`로 추가: Name `Pleos Connect System Image`, URL `https://nexus-playground.pleos.ai/repository/raw-releases/connect-avd/2.x/crp-sys-img.xml`).
2. **SDK Platforms** 탭 → 하단 "Show Package Details" 체크 → Android API 34 아래 "Pleos Connect v2.1.0 APIs Intel x86_64 Atom System Image" 체크 → OK → 라이선스 동의 → 설치.
3. 설치 후 Android Studio 재시작.

### 3.3 Automotive AVD 생성
**CLI:**
```bash
export JAVA_HOME="E:\\AndroidStudio\\jbr"
cd /e/Android/Sdk/cmdline-tools/latest/bin
./avdmanager.bat --verbose create avd -n Pleos_Connect_2_1_0 \
  -k "system-images;android-34;pleos_car_emulator;x86_64" \
  -d "automotive_1024p_landscape" --force
```
- 디바이스 프로필 이름은 `./avdmanager.bat list device | grep -i auto`로 먼저 확인할 것(버전에 따라 `automotive_1024p_landscape`, `automotive_1080p_landscape`, `automotive_portrait` 등).
- 생성 후 `C:\Users\H\.android\avd\Pleos_Connect_2_1_0.avd\config.ini`를 열어 아래 값 확인/수정(공식 문서 권장값):
  ```
  hw.ramSize=4096
  fastboot.forceColdBoot=yes
  fastboot.forceFastBoot=no
  hw.gpu.enabled=yes
  hw.gpu.mode=host
  ```

**GUI(공식 문서 절차):** Tools → Device Manager → Create device → Form Factor **Automotive** → "Pleos Connect v2.1.0" 선택 → Next → Advanced Settings: Startup > Default boot **Cold**, RAM **4 GB** → Device 탭 API **34**, "Pleos Connect v2.1.0 APIs" 선택 → Finish.

## 4. 알려진 주의점
- `sdkmanager --list`는 Pleos 저장소까지 조회하므로 1~2분 걸릴 수 있음.
- 이전 버전 Pleos 에뮬레이터 이미지가 있으면 삭제 후 설치하라는 공식 안내 있음 → 이 PC에는 없음.
- 에뮬레이터는 x86_64 이미지이므로 Hyper-V/WHPX 또는 AEHD 가속 필요. Hypervisor present=True라 WHPX로 동작할 가능성이 높음. 느리면 `extras;google;Android_Emulator_Hypervisor_Driver` 설치 검토.
- Vehicle SDK API는 `checkXXXCapabilities`로 지원 여부를 먼저 확인해야 하고, 퍼미션은 승인 범위 내에서만 선언 가능(미승인 시 앱 심사 불통과).
